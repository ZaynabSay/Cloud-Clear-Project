# Cloud & Clear Dashboard

> My first web development project. An interactive weather app with a live globe.

---

## What It Does
-  Search **any city, state or country** worldwide
-  Interactive satellite globe
-  Shows current weather, temperature, humidity & wind speed
- 3-day weather forecast
- Toggle real time overlays: Clouds, Rain, Temperature, Wind, Pressure

---

## Built With
**HTML5**, **CSS**, **JavaScript** only

Uses free weather & map data from OpenWeatherMap & MapLibre

---

**[Click Here to Open the App](https://zaynabsay.github.io/Cloud-Clear-Project/)**

## How to Use
1. Type any city, state, country name in the search box
2. Click enter
4. Toggle overlays on the left to see maps of clouds, rain, temperature etc.

---

## About This Project
This is my very first web development project, built from scratch whist also learning HTML, CSS & JavaScript. I wanted to make something visual, interactive and useful for day to day life.

This app uses a free weather API, you'll be asked to paste a free API key from OpenWeatherMap.org once when you first use it. It saves automatically in your browser.
